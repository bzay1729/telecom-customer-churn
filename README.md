# Telecom Customer Churn Prediction

An end-to-end machine learning project that predicts customer churn risk for a telecom company.

## Business Problem

Customer churn happens when a customer stops using a telecom service. This project predicts which customers are likely to churn so a retention team can prioritize outreach.

## Planned Stack

- Python, Pandas, NumPy, scikit-learn
- FastAPI and Streamlit
- Docker and GitHub Actions
- Cloud deployment
